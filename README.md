# Weather Data Fetch Using OpenWeather API

A small Node.js + Express app that looks up a city and displays the full current-weather response from the [OpenWeather API](https://openweathermap.org/current).

## Setup

1. Install dependencies: `npm install`
2. Get a free API key from https://home.openweathermap.org/api_keys
3. Create your env file: `cp .env.example .env` and add your key
4. Start the server (Node 20.6+): `npm start`
5. Open http://localhost:3000 and search for a city

## Tech
Node.js, Express, Axios
